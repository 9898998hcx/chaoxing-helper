# Step 0：PRD 与 MVP 范围

版本：2026-10-22。状态：默认方案已获用户确认；本次本地源码交付，不发布线上服务。

## 产品与边界

面向个人中文求职者，帮助用户整理经历、使用 AI 改善表述、参考合规模板结构并下载可投递 PDF。免费单人使用；暂不包含支付、多人协作、职位投递、完整模板源文件交易、多语言和自动编造经历。

| 能力 | MVP 范围 | 验收边界 |
| --- | --- | --- |
| 注册登录 | 邮箱密码、哈希密码、服务端会话、退出、可配置邮箱验证 | 本地验证可关闭；生产默认强制验证；无 SMTP 时明确失败 |
| 简历 CRUD | 创建、列表、编辑、复制、删除、版本快照/恢复 | 每次读写均隔离 userId；并发修改返回 409 |
| 在线编辑 | 基本信息、求职意向、教育、工作、项目、技能、证书、自我评价 | 排序、隐藏、自动保存、左右预览、移动端切换 |
| DeepSeek | JD/经历生成模块、润色、自我评价、改进建议 | 服务端 Key、结构化校验、超时重试、额度限制；必须预览后采纳 |
| PDF | 当前已保存简历生成 A4 PDF，原创样式选择 | 中文字体、页边距、分页、权限、大小/并发限制 |
| 模板库 | 列表、标签筛选、详情、来源链接、规则推荐 | 只展示已审核元数据；不复制第三方正文和图片 |
| 模板参考生成 | 仅使用模块顺序、布局标签、风格约束 | 用户确认后写入，保存模板 ID，模板失效时安全降级 |
| 最小后台 | 来源配置、任务触发、审核/下架、任务记录、审计 | 管理员鉴权，来源默认禁用，采集总开关默认关闭 |

## 页面与用户流程

| 页面 | 路径 | 主要行为 |
| --- | --- | --- |
| 首页 | `/` | 产品入口、原创简历预览、注册登录 |
| 注册/登录 | `/register`、`/login` | 表单校验、验证提示、登录后进入简历列表 |
| 邮箱验证 | `/verify-email` | 消费一次性令牌、重发邮件 |
| 简历列表 | `/resumes` | 创建、打开、复制、确认删除 |
| 简历编辑 | `/resumes/:id` | 左表单右预览、自动保存、版本恢复 |
| AI 助手 | 编辑器内面板 | 选择场景、输入 JD、等待、预览、采纳/放弃 |
| 模板库/详情 | `/templates`、`/templates/:id` | 筛选、结构推荐、来源、使用此结构生成 |
| PDF 下载 | 编辑器内操作 | 等待保存完成、选择原创样式、生成、下载 |
| 后台 | `/admin` | 来源审核、采集任务、模板审核/下架 |

主流程：注册 →（配置要求时验证邮箱）→ 登录 → 创建简历 → 编辑并自动保存 → AI 预览/采纳 → 参考模板结构 → 保存 → PDF 下载。AI 未配置时可继续手动编辑与导出。管理员流程：运维赋权 → 登记来源与许可证据 → 显式启用来源及总开关 → worker 采集 → 人工审核 → 展示；投诉后立即下架并留审计记录。

## 技术选型与第三方服务

- Next.js/React：页面路由、SEO、响应式编辑器；NestJS：模块、守卫与依赖注入。
- Prisma：类型化数据库访问。开发默认 SQLite；生产使用独立 PostgreSQL schema/迁移，不能混用 SQLite 迁移。
- 本地内存限流：无需额外安装，重启清空且仅单进程；生产 Redis：共享限流、配额及 BullMQ 队列。
- Playwright/Chromium：受控服务端 HTML 转 PDF，使用 Noto Sans CJK 开放字体。
- BullMQ 独立 worker：采集不占 Web 请求，不配置 Redis 时不启动采集。
- S3 兼容存储：可选 PDF 私有归档；默认直接下载、不持久化敏感 PDF。
- DeepSeek API：仅后端调用；SMTP 邮件供应商：验证邮件；S3 供应商：可选对象存储。

## 风险与缓解

| 风险 | 处理 |
| --- | --- |
| 简历隐私及越权 | 服务端 owner 条件、会话 cookie、CSRF、日志不保存正文 |
| AI 虚构事实/提示注入 | 明确不编造、限制输出结构、转义文本、用户逐次确认 |
| AI 费用与不稳定 | 用户限流、每日额度、月度 token 上限、超时、有限重试；用量日志只存计数 |
| 模板版权与站点条款 | 默认禁用、记录许可证据、robots 检查、仅元数据、人工审核与下架 |
| SSRF/恶意页面 | 禁内网、重定向重新校验、固定 DNS、体积/超时上限、无脚本抓取 |
| PDF 资源耗尽/中文缺字 | 原创受控模板、禁止外部请求、容量/并发限制、安装字体 |
| 并发覆盖与数据丢失 | revision 乐观锁、串行自动保存、版本快照、备份与恢复说明 |
| 本地替代与生产差异 | 内存不承担多实例限流；PostgreSQL/Redis/容器列独立上线检查 |

## 已确认的 8 项默认答案

1. 目标部署：单台 Linux + Docker Compose；本轮本地源码交付，暂不验证 Docker 运行。
2. 邮箱验证：开发关闭，生产默认开启。
3. 采集策略：仅明确授权/允许的来源；未知来源默认禁用，不内置可采集来源。
4. 管理后台：保留最小后台，运维命令指定管理员。
5. PDF 字体：Noto Sans CJK，保留开放许可证；本地无字体时需按文档安装。
6. DeepSeek：每用户每天 20 次、每分钟 5 次，月度 token 总上限可配置；未启用付费服务。
7. 存储：本地 SQLite/内存；生产 PostgreSQL/Redis，自建；S3 可选。
8. 用户：中文个人求职，免费，不含支付和协作。

上线前仍需提供：实际域名/HTTPS、SMTP 凭据、DeepSeek Key 与金额预算对应的 token 上限、授权采集来源证据、备份位置。凭据不写入代码仓库。
