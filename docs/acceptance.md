# MVP 验收清单

本文件列出应执行的验收步骤。复选框默认未勾选，不表示功能已在目标环境通过；实际自动测试结果以本次执行记录和 CI 为准。Docker、真实 DeepSeek、SMTP、S3、生产 PostgreSQL/Redis 与真实采集来源均未在本次自动运行，需部署方补做联调。

使用两个独立浏览器会话注册用户 A 和 B，资料均为虚构。使用普通用户、管理员分别验证权限。先运行本地迁移与原创模板种子；默认爬虫关闭、DeepSeek Key 为空。

## 注册、登录与会话

- [ ] 注册有效邮箱和符合要求的密码；重复邮箱有明确提示，失败不泄露密码。
- [ ] 错误密码与未登录请求被拒绝；刷新页面能恢复会话；退出后旧会话失效。
- [ ] 开启邮箱验证时，完成 SMTP 发送、链接有效期/单次使用、未验证账号限制；没有 SMTP 的错误可理解。
- [ ] 删除 Cookie 或 CSRF token 后执行修改请求失败；从其他 Origin 伪造请求返回 403。
- [ ] 短时间重复登录触发限流；生产 Cookie 包含 Secure、HttpOnly 和 SameSite。

## 简历 CRUD 与编辑器

1. 用户 A 从简历列表新建简历，进入左表单/右预览的编辑器。
2. 填写基本信息、求职意向、教育、工作、项目、技能、证书、自我评价；预览随编辑更新。
3. 增删重复经历项，调整模块顺序，隐藏模块，再恢复显示；确认预览与保存结果一致。
4. 等待保存成功提示后刷新；确认所有内容、顺序、可见性恢复。
5. 创建版本快照后修改，再恢复指定版本；恢复生成新的版本，历史不丢失。
6. 同时打开两个标签页编辑同一简历，旧版本保存应冲突提示，不能静默覆盖新内容。
7. 返回列表复制简历，确认副本独立可编辑；删除时二次确认，取消不会删除。
8. 用户 B 直接访问 A 的读取、修改、复制、删除、历史、恢复、AI 和 PDF URL，均返回 403/404；B 的列表看不到 A 的简历。

- [ ] 上述步骤通过，保存期间/失败/冲突状态清楚。
- [ ] 断网保存失败时不显示已保存，重试后内容仍在。
- [ ] 手机宽度可切换表单与预览，输入、排序、隐藏和保存可用。

## DeepSeek AI 助手

- [ ] 无 Key 时返回明确的服务未配置错误，不覆盖已有内容。
- [ ] 测试服务模拟超时、429、5xx、非法 JSON、字段缺失；确认有限重试、超时和安全错误映射。
- [ ] JD + 经历生成指定模块，已有内容润色、自我评价与改进建议都有结构化预览。
- [ ] “放弃”保留原内容；“采纳”后才写入简历，自动保存后可继续人工编辑。
- [ ] 检查 `AiGenerationLog` 包含用户、场景、token 估算、耗时和状态，搜索测试敏感字符串应不存在。
- [ ] 达到日额度、每分钟限额或月 token 限额后有提示；刷新不能绕过服务端限制。
- [ ] 使用真实 Key 的费用、质量和供应商返回值已单独验收；提醒内容不能凭空编造经历或量化成果。

## PDF 导出

- [ ] 编辑内容先保存成功，再选择不同样式导出；PDF 使用本人当前已保存数据。
- [ ] 打开中文、英文、标点与多页长简历，确认字形、分页、A4 页边距与文字复制正常。
- [ ] 隐藏模块不出现在 PDF，模块顺序与简历一致。
- [ ] 文件名含安全的 ASCII 兼容名和 UTF-8 文件名，不含换行或路径控制字符。
- [ ] B 无法下载 A 的 PDF；无权限时不启动浏览器渲染。
- [ ] 缺浏览器/字体、超时、输入过大、输出过大与繁忙均返回明确错误。
- [ ] Android/iOS 浏览器可触发并保存或分享 PDF；需实际设备验收。

## 模板库、推荐与参考生成

- [ ] 模板列表支持标签/风格/行业筛选，空结果有清楚提示；详情有来源链接与结构说明。
- [ ] 按岗位、行业和经历推荐；未配置 AI 时仍可用标签与简单相似度得到结果。
- [ ] 无匹配模板时能够降级使用默认结构，生成入口不被阻塞。
- [ ] 详情“使用此结构生成”进入自己的简历或引导创建简历。
- [ ] 查看生成请求的服务端构造逻辑：仅注入模块顺序、布局标签和风格约束，不注入第三方正文、源文件或图片。
- [ ] 预览采纳后保留来源模板 ID，生成内容可继续编辑；放弃不会更改简历。
- [ ] 下架模板不再出现在列表、详情与新生成流程中。

## 爬虫与后台审核

- [ ] 普通用户访问全部 `/api/admin/*` 返回 403；管理员可查看来源、任务、待审核模板与审计。
- [ ] 默认全局关闭时触发采集返回 `CRAWLER_DISABLED`；内存 Redis 模式拒绝启动真实队列。
- [ ] 未启用、未确认授权、缺少 ToS 依据或 robots 检查的来源不能采集。
- [ ] robots 禁止/不存在/不可读取时任务 SKIPPED；遵守来源间隔与更长的 crawl-delay。
- [ ] 私网、环回、云元数据、多 DNS 含私网、跨来源/越界重定向被拒绝。
- [ ] 相同规范化 URL 重复采集不重复入库，不会复活已拒绝或下架记录。
- [ ] 只保存允许的元数据；附带正文、源文件字段的行被丢弃，不抓取完整图片。
- [ ] 新记录仅待审核，批准后才能公开；下架立即对公共读取生效并留下理由与审计。
- [ ] 修改来源 URL/条款/范围后复核授权；停用来源后不再发出后续采集请求。
- [ ] 真实来源必须逐一复核条款、授权和 robots；本次没有自动启用任何外部来源。

## UI、可访问性与完整流程

- [ ] 注册/登录 → 创建简历 → 编辑 → AI 预览采纳 → 选择模板 → PDF 下载全流程通过。
- [ ] 列表空状态、加载、断网/服务失败、保存冲突、配额耗尽与重试操作清楚。
- [ ] 输入项有标签、必填/长度校验与可理解错误；键盘可访问所有核心操作，焦点可见。
- [ ] 320 px 手机、平板与桌面布局无横向溢出；按钮触达和预览切换可用。
- [ ] 页面标题/描述、语义结构、状态播报与颜色对比经过检查；删除/版本恢复等敏感操作有确认。

## 安全与部署

- [ ] 单元、集成、E2E、类型检查、生产构建和依赖审计通过。
- [ ] 不在前端 bundle、Git、日志、错误响应中出现密钥、Cookie 或完整敏感简历。
- [ ] Docker Compose 构建、PG 迁移、健康检查、Redis 限流与独立 Worker 在目标服务器验收。
- [ ] 默认公开端口仅 Web；生产 HTTPS、SMTP、S3 私有权限、备份恢复与监控已验证。
- [ ] DeepSeek 预算提醒与真实账单告警已演练；采集开关/授权/下架负责人已明确。

部署步骤与上线检查详见 `09-deployment.md`；API 字段与错误码详见 `02-api.md`；来源策略详见 `06-crawler.md`。
