# 学习通课程助手 · DeepSeek

一个 Chrome / Edge 浏览器扩展（Manifest V3），四个功能模块：

| 模块 | 能力 |
|---|---|
| 🎬 课程视频自动播放 | 自动开始播放、断播自动恢复、挂机提示自动点击、自动识别视频播放完成并进入下一节 |
| 🪟 页面悬浮控制器 | 视频页右下角**自动弹出**控制面板：播放 / 暂停、进度、状态（学习页上与任务点助手合并为同一个「学习通助手」面板） |
| 📚 学习通助手（学习页） | 右下角合并面板：**视频控制**（播放 / 暂停 / 进度）+ **任务点管理**（识别本节全部任务点，由用户选择播放下一个视频或打开下一个图文，一键完成；图文自动滚动阅读） |
| 🧭 侧边视频控制器 | 浏览器侧边栏常驻面板：手动播放 / 暂停、实时进度、一键开关自动播放/连播/防挂机 |
| 📚 DeepSeek 辅助答题 | 识别作业/测验题目（单选/多选/判断/填空/简答）→ 调用 DeepSeek 生成答案 → 自动点选/填写，可选自动提交 |

> 答案由 AI 生成，请自行核对；**仅供本人已选课程的学习辅助使用，请遵守学校与课程规定，考试中请勿使用自动答题。**

## 安装

1. 打开浏览器扩展管理页：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
2. 打开右上角「**开发者模式**」
3. 点击「**加载已解压的扩展程序**」，选择本文件夹（`chaoxing-helper`）
4. 安装完成，工具栏出现扩展图标

> 已安装过旧版？在扩展管理页点击该扩展卡片上的「刷新」按钮即可加载新版本。
> 侧边栏功能需要 **Chrome / Edge 114+**（`sidePanel` API）。

## 配置

1. 点击工具栏扩展图标，打开设置弹窗
2. 填写 **DeepSeek API Key**（在 [platform.deepseek.com](https://platform.deepseek.com) 申请，形如 `sk-...`）
3. 按需勾选开关，点击「保存设置」（立即生效，无需重启浏览器）

| 开关 | 说明 |
|---|---|
| 自动播放视频 | 进入课程页自动开始播放 |
| 自动连播下一节 | 自动识别视频播放完成（`ended` 事件 + 进度轮询兜底），随后进入下一节 |
| 防挂机自动点击 | 定期点击「继续播放 / 我知道了」等提示 |
| 进入答题页自动开始 | 打开作业/测验页后自动扫描并作答 |
| 答完自动提交 | **默认关闭**；开启后提交前仍会弹确认框 |

> 视频倍速：1.0x 最稳；倍速过高有被平台判定异常的风险，请自行斟酌。

## 使用

### 🪟 页面内悬浮控制器（视频页自动弹出）

打开学习通课程学习页（如 `mooc2.chaoxing.com/mycourse/studentstudy`），**视频检测到后右下角会自动出现「视频控制」小面板**：

- 实时状态与进度（播放中 / 已暂停 / 完成 + 时间）
- **▶ 播放 / ⏸ 暂停** 一键控制（暂停后不会被自动恢复逻辑抢播，直到你再次播放）
- 点击「×」关闭；刷新页面后重新出现

> 这就是“自动播放视频弹窗”——现在它出现在学习通页面内，无需打开浏览器侧边栏或扩展菜单。

### 视频自动播放

打开学习通课程学习页，视频会自动播放；被挂机提示打断会自动点「继续播放」。

视频播放完成后会自动进入下一个视频：

- **完成识别**：同时监听 `ended` 事件与播放进度（`currentTime ≥ duration - 1.2s` 且已暂停即判定完成），播放器停在最后一帧不触发 `ended` 也能识别
- **分段视频**：同一章节有多个分段时，先在本播放器内点「下一集」
- **进入下一节**：跨章节时自动点击「下一章/下一节」按钮；找不到按钮则回退到侧边栏第一个「未完成」章节
- **防跳章**：点击后会校验页面/iframe 是否真的切换，避免重复点击一下跳过多节

### 🧭 侧边视频控制器

**打开方式**：

1. 点击工具栏扩展图标 → 弹窗中点击「🎬 打开视频控制面板（浏览器侧边栏）」
2. 点击浏览器右上角的**侧边栏图标**（Chrome 侧边栏 / Edge 侧边栏）→ 选择「学习通课程助手」

面板显示实时状态、进度、播放/暂停按钮和快捷开关；控制的是当前活动标签页里的学习通视频。

### 📚 学习通助手（学习页，视频控制 + 任务点合并）

打开学习页（课程 → 章节 → 点击小节），右下角会出现「学习通助手」面板：

**视频控制区**（合并自原悬浮控制器）
- 实时状态与进度（播放中 / 已暂停 / 完成 + 时间）
- **▶ 播放 / ⏸ 暂停** 一键控制（暂停后不会被自动恢复抢播）
- **倍速控制：1x / 1.5x / 2x**，选中后立即设置；**未完成任务点的视频会被平台强制 1x**（面板会提示并恢复），已完成任务点的视频 / 非任务点视频可正常倍速
- 无视频时显示「未检测到」

> ⚠️ 平台对任务点视频要求「观看时长 ≥90%、未完成前不可倍速」，倍速播放**可能导致任务点不计入完成进度**，请谨慎使用；日常学习可放心使用倍速。

**任务点区**
- 自动识别本节**全部任务点**，显示类型（▶ 视频 / 📄 图文）和完成状态
- **▶ 下一个视频**：定位到下一个未完成的视频任务点并自动播放
- **📄 下一个图文**：打开下一个图文任务点，并**自动逐段滚动**阅读到底
- **⚡ 自动完成全部**：按顺序自动处理本节所有待完成任务点
- 也可以直接点击列表中的任意任务点单独打开
- **⏮ 上一章节 / ⏭ 下一章节（合并一行）**：手动回退或前进到相邻章节，选择权在你；勾选「完成本节后自动跳转下一节」则本节任务点全部完成后自动进入下一节（可随时取消勾选）
- **面板可拖动**：按住面板标题栏可拖到任意位置，位置会自动记住
- **悬浮球**：点标题栏「—」折叠成小圆球，点球展开面板；球也可拖动

> 选择权在你：面板只在你点击按钮时行动。平台对视频任务点要求**观看时长 ≥ 90%**（未完成前不可倍速、不可拖拽），请保持 1x 播放。

### 答题 / 自动刷题

打开作业 / 测验页面（URL 含 `/work/`、`/exam/` 等），右下角出现 **「📝 刷题助手 · DeepSeek」** 面板：

1. 先在扩展图标弹窗中配置 **DeepSeek API Key**（未配置时面板会提示）
2. 点击「**⚡ 自动刷题**」（或依赖「进入答题页自动开始」开关），逐题由 DeepSeek 生成答案并自动填选
3. 面板实时显示进度（正在刷题 X/N）；每题作答后卡片描绿边（✅），失败描黄边（⚠️ 需手动处理）
4. 全部完成后**核对答案**，再手动点击平台提交按钮（或开启自动提交，会先弹确认框）

## 工作原理

- **视频与悬浮面板**：内容脚本注入所有 chaoxing / xueyinonline 页面（`all_frames: true`）。在视频 iframe 内定位 `<video>` 并自动播放；视频帧每 2 秒通过 `postMessage` 把状态中继到顶层帧，顶层帧渲染悬浮控制器；面板按钮通过 `postMessage` 广播命令回各视频帧。视频帧同时每 2 秒向后台上报状态（`cxh-status`）供侧边栏使用。
- **完成检测与连播**：`ended` 事件 + 进度轮询兜底；完成后优先本帧「下一集」，否则通知顶层点「下一章节」，并用快照对比确认切换成功。
- **答题**：仅在 `/work/`、`/exam/` 等答题页注入。解析题目卡片（`.questionLi` / `.TiMu` 等多选择器回退），把「题型 + 题干 + 选项」发给后台，后台用你配置的 API Key 调用 `https://api.deepseek.com/chat/completions`，返回答案后由内容脚本按题型点选/填值（对 React 受控输入使用原生 setter 并派发 input/change 事件；简答题兼容 UEditor 富文本 iframe）。

## 局限与注意

- 自动连播严格等待视频**自然播放到结尾**才会切换（暂停在结尾或拖动进度条到结尾不会触发跳转）。
- 学习通页面结构可能随平台更新而变化，导致题目解析或按钮文本匹配失效。失效时主要改这几处：
  - `content/answer-helper.js`：`getCards()`（题目卡片选择器）、`detectType()`（题型关键词）、`extractOptions()`（选项解析）
  - `content/video-player.js`：`PROMPT_TEXTS`（挂机提示文本）、`NEXT_TEXTS` / `findNextControl()`（下一节按钮匹配）、`sidebarNext()`（侧边栏「未完成」回退）
- 视频播放中途弹出的「**弹题**」不会自动作答，需手动作答后视频才继续。
- 浏览器自动播放策略：首次进入页面可能被拦截，手动点击一次视频即可，之后自动恢复。
- 简答题的富文本编辑器若不可访问（跨域 iframe 除外），会自动降级为普通输入框或提示手动填写。
